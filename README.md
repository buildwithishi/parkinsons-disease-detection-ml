Parkinson’s Disease Detection using Machine Learning:

This project builds a Machine Learning system to detect Parkinson’s Disease using Python. It uses a Support Vector Machine (SVM) classifier to predict whether a person is Parkinson’s positive or does not have the disease, based on the given dataset.

Project Overview:

Dataset- [Kaggle Parkinson Disease Detection Dataset](https://www.kaggle.com/datasets/debasisdotcom/parkinson-disease-detection?resource=download)

Objective- Predict whether a patient has Parkinson’s disease

Algorithm Used- Support Vector Machine (SVM)

Performance- Achieved similar training and testing accuracy, indicating good generalization

Outcome- A predictive system that takes patient data as input and returns the predicted status


Tech Stack:

Python, Scikit-learn, NumPy, Pandas, Google Colab
